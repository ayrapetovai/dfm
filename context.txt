# DFM — dotfile manager (Rust)
## What dfm is / main goals
Syncs dotfiles between a **target** dir (usually `$HOME`) and a **source** dir (a git repo like `~/dotfiles`). Commands: `init`, `add` (target→source), `pull` (source→target), `sync` (both directions, already-managed only), `merge`, `diff`, `forget`, `purge`, `ignore`, `paths`, `config`, `status`, `encrypt`, `decrypt`. Global flags: `-n/--dry-run`, `-v <0-3>` (1 default, 2 info, 3 debug), `-c <PATH>` alt config.

- **Local only**: sync between two dirs on one machine; never talks to git servers/network/cloud; git commands NOT embedded into dfm.
- **State-driven**: decisions come from `state.toml` (`SyncTime{mtime, sha256}`), not from scanning alone; content hash makes change detection deterministic.
- **Failure-safe**: atomic writes (sibling temp + `rename`); mutating ops queued as task enums, executed in a final loop; state committed once (all-or-nothing per run).
- **Deterministic output** (status sorted by path; `--porcelain`/`--short` frozen, uncolored, never paged) + **encrypted sources** as self-contained blobs (never plaintext in source).
- **Root guard**: refuses elevated root (sudo/setuid); bypass `DFM_ALLOW_ROOT` (any non-empty value).

## Layout
`src/main.rs` dispatch; `src/cli.rs` clap Args (`#[path]`-included by build.rs); `src/lib.rs` DfmError/Settings/Config/StateObject, path+ignore helpers, `list_directory`, `compare_files`, ActionBar, unit tests; `src/crypt.rs`; `build.rs` → dfm.1; `src/commands/{add,pull,sync,merge,diff,forget,init,ignore,purge,config,paths,status,encrypt}.rs` + `mod.rs` shared helpers.

## Key types & files (lib.rs)
- **DfmError**: `Io/Unsupported/NotFound/InvalidData/InvalidInput/Other`; helpers `other(msg)`, `is_permission_denied()`; `From<io/toml/regex/microxdg>`.
- **Settings/Config**: same fields (Config = optional TOML); source/target dirs ONLY in the state file, not config. Tool defaults: merge `vimdiff {target} {source} {result}`; diff `vimdiff -M {target} {source}` (read-only); `diff_all_tool_command_target` `diff -u --color=always {source} {target}`, `..._source` reversed; `diff_editable_tool_command` `vimdiff {target} {source}` (writable).
- **StateObject**: `{source_directory, target_directory, syncs: HashMap<String, SyncTime>}`; key = source-relative path; `validate_state_key` rejects `..`/absolute/drive components on read (tamper hardening).
- **SyncTime**: `{mtime: SystemTime, sha256}`; mtime serialized `"<secs>;<nanos>"`; sha256 = hex of content at last sync.
- Paths: config `$XDG_CONFIG_HOME/dfm/config.toml` (fallback `~/.dfm.toml`); state `$XDG_STATE_HOME/dfm/state.toml`; target ignore `$XDG_STATE_HOME/dfm/ignore_file`; source ignore `<source>/.dfm_ignore_file`; marker `<source>/.dfm_root`. Non-UTF-8 paths via `to_string_lossy()`, never `to_str().unwrap()`.
- main.rs needs the state file for add/pull/forget/merge/diff/status (`NotFound` otherwise); init/config/purge/ignore/paths work without it. Missing config → silent defaults; corrupt config → warning.
## Path encoding (lib.rs)
- target→source: leading `.` → `dot_prefix` (`dot_bashrc`↔`.bashrc`); `add_postfix_opt` appends `.symlink`/`.encrypted` **to the full filename**. Injective: literal `dot_` → `~dot_…`, literal `~` → `~~…`; `source_rel_to_target_rel` inverts component-wise.
- `file_path_relative_to(abs,dir)`; `remove_dots_from_path` resolves `.`/`..` lexically.

## Ignore matching (lib.rs)
One regex per line; `#` comment (`\#` escapes); blank skipped → `RegexSet`. **Root-anchored component matching**: pattern split on `/`, each sub-pattern anchored `^(?:…)$` unless it has own `^`/`$`; single sub-pattern **with** a left-glob matches any component, **without** it only the first; multi-part matches in order (no sliding); `dirname/` ≡ `dirname`. `dfm ignore PATH` stores `regex::escape` of the lexical target-relative path (symlink records itself); source-side paths → source ignore as `^<target-rel>$` stripped of `dot_`. `force_encryption_for` uses full-path substring matching. Dir-subtree probe = `R + "/x"` sentinel.

## Conflict detection — `compare_files(encrypted_postfix, TF, SF, sync)`
both_not_modified    = TF==sync && sync==SF
only_source_modified = (TF==sync && sync<SF) || TF<SF
only_target_modified = (TF>sync && sync==SF) || TF>SF
both_modified        = TF>sync && sync<SF   → also NeverSynchronized (no entry)
Fallback `<`/`>` covers mtime granularity. Encrypted compare by timestamps (re-encryption changes bytes); plain by sha256 vs stored hash; `sync` = stored `SystemTime`.

## Shared helpers (commands/mod.rs)
- `sync_file_copy` (copy + perms + mtimes + state); `update_sync_state` (sha256 + `SyncTime{now}`); `get_sync_time`/`remove_sync_state`.
- `resolve_source_variant` → `{Plain,Encrypted,Symlink}` (encrypted→plain→symlink order).
- `source_rel_to_target_rel` / `source_rel_to_target_abs` (source→target mapping: pull, merge, status, purge).
- `cli_path_to_abs`: absolute → `remove_dots`; relative → join **CWD** + lexical normalization. `cli_path_in_scope`: that + must start_with target OR source else `InvalidInput`; wired into status/add/pull/merge/forget/ignore. **diff stays permissive** ("not managed").
- `resolve_dry_run`, `require_force`, `prune_ignore_file`, `prune_matched_ignore_patterns` (after add/pull `--force`), `is_ignored` (bool only, never prunes — sync), `read_symlink_pointer`, `split_command` (whitespace-split template → program+args), `resolve_tool_command` (→ tool or `Other("no {tool} tool configured — set {key}")`).
- `run_merge`/`run_diff`: `.current_merge`/`.current_diff` scratch dirs (0700, `DirGuard` cleans up). All tool spawns via `run_tool(prog,args,label)` — **directly, no shell** (`|`,`>` don't work). diff scratch only for **encrypted** sources (plain diffs pass `{source}` through → works on read-only source dirs); `Scratch` (diff.rs) lazy 0700 create, `file_for(role,target)`. `run_diff_capture` (batch) forwards stdout lossily (`from_utf8_lossy`). Progress: `ActionBar` (stdout `\r`, **TTY-only** via `io::stdout().is_terminal()`); labels `reading` (walk+analysis/filter/sort), `processing` (planned tasks, 1 step/task), `formatting output` (default `status` report formatting, spans `format_default`, counter advances inside `collapse_shared_dirs` rescans — unit of work per examined path, no fixed total); suppressed entirely on pipes/redirects and for `status --porcelain`; enabled regardless of `-v`/`-n`; clears before the command's own output. Small batches (`total ≤ ACTION_SMALL_BATCH=100`) render every task; walk phase (`total=None`) renders at `ACTION_WALK_STEP=500`-entry steps; large totals render on percent change or final step. `ActionBar::with_sink(label, sink, enabled)`/`suppressed(label)` for tests (unit `action_bar_tests`). The `formatting output` bar is created in status.rs's default branch, passed into `format_default` (and `collapse_shared_dirs`) as `&mut ActionBar`; it increments per path examined inside the collapse. `collapse_shared_dirs` decides foldability bottom-up in ONE pass (O(n×depth), no per-fold rescans — fixing a quadratic blow-up on big homes): a blocked path severs all its ancestor prefixes (closure precomputed once), a dir folds iff after its directly-folding children collapse to one member each at least 2 members remain (so a chain empty except a collapsing leaf folds only there), and each fold emits `{dir}/*` at its first member's position. Total is unknowable up front so the bar counts units of work (`total=None`), `examined` accumulates monotonically across all report groups; `formatting_done` also counts rendered display lines. Cleared before `print_paged`. `list_directory_with_progress`/`list_directory_or_error_with_progress` accept an `on_entry` callback wired to the bar; old stderr `ProgressLine`/`report_progress`/"traversing..." heartbeat removed.

## Command semantics (key contracts)
- **init**: create source, `.dfm_root` chain, extend source ignore (`.dfm_root`, `.git`, ignore-file entries, `.current_merge`, `.current_diff`), state file + default config. Never looks for config inside source.
- **add**: skip dfm runtime files (state, target-ignore) and out-of-target paths; **config file is NOT skipped** (manageable dotfile). Symlink → pointer (no pointee fallthrough). Ignored → skip unless `--force` (`handle_ignore_or_override` also prunes the pattern, symlinks too). Conflicts need `--force`; `conflict_detected` only for explicitly-named paths. `-s`/`-e` exclusive; `-e` on symlink errors; encrypted add deletes stale plain source+state. `CopyAndSymlink` renames target → `.dfm-backup` sibling, drops backup only on success (restores on failure).
- **pull**: reverse mapping; missing target → per type `CreateOrUpdateSymlink`/`Decrypt`/`Copy` (symlink with `-s`); encrypted uses `handle_encrypted_timestamps` (Both/Target/NS → `--force`, Source → decrypt).
- **sync**: only files with a source **and** a sync record eligible (unmanaged/never-synced/unpulled skipped). NonModified→skip; SourceModified→pull; TargetModified→add; BothModified→conflict. No `--force`: traverse eligible, exit≠0 when conflicts exist (nothing modified). `--force`: conflicts not errors, copy eligible, never touch conflicts, exit 0. Ignored never processed (with or without `--force`; `is_ignored`, no pruning — sync never edits the ignore file). No `--symlink`/`--encrypt` conversions. Uses shared helpers (`list_directory` PruneIgnoredDirs, `resolve_source_variant`, `get_sync_time`, `compare_files`, `update_sync_state`); traversal symlinks via `handle_symlink`/`UpdatePointer` (pointer-file layout only); encrypted pairs via `AddEncrypted`/`PullEncrypted`.
- **merge**: no paths → only `BothModified`; paths → any modified. `resolve_state_key` exact → encrypted → symlink, skips a stale plain entry whose source file no longer exists (`test_merge_stale_plain_entry.sh`). Tool success = exit 0 AND result exists; copy result to both sides (re-encrypt if needed), `update_sync_state`, clean up.
- **diff**: read-only except `--editable`. No-arg (or `-a/--all`) = **batch mode**: diffs every modified managed file via non-interactive templates (BothModified uses the target one), `DiffSink` streams each child's stdout (straight to stdout if not a TTY; else buffered + paged once via `print_paged`); up-to-date + never-synced silent; permission-blocked side warned+skipped via `path_exists`. Encrypted decrypted to lazy `.current_diff` scratch (DirGuard; plain-only leaves no scratch → read-only source OK). Path args → per-path `diff_tool_command`. Situations: `is not pulled`/`is not managed`/`does not exist`/`is ignored by <re>`. Decrypted content as **file only**, never stdin (vim `:qa` fails on `[No Name]`). **`--editable`** (`-e`, requires paths, conflicts with `--all`): only writing diff mode; `resolve_pair` must be a regular `Pair` (else `InvalidInput`); sides copied to `.current_diff` (`target.<f>`/`source.<f>`, encrypted decrypted there, chmod `|0600`); **no equality check**; tool = `diff_editable_tool_command`, non-zero exit → error, nothing written, scratch removed; each changed side written back independently (sha256 vs **own** original; encrypted source re-encrypted **from the edited copy** via `crypt::write_encrypted_source`, inner name/mode/dirs from the target) + `update_sync_state` **only when the two saved files end up equal**; `--dry-run`: prepare copies only, no tool/write (read-only source friendly). `test_diff_tool_replaced.sh` proves config-driven tool switching.
- **forget**: never deletes targets. No paths → all (traverse target + orphan state keys). Explicit path resolving to nothing → `NotFound("<path> does not exist")`, before any task, exit 1, `--force` doesn't suppress. 3 phases: best-effort delete sources → remove state → prune empty parents. Dispatched via `with_state_even_if_error`. **ignore**: `-p` raw, `-r` remove, mutually exclusive (ArgGroup; no args = CLI error). Appends with trailing-newline guard. **purge**: abort (unless `-f`) on un-pulled changes; removes config (unless `-c`), source (unless `-s`), state dir; config parent dir removed only for the default config (never `$HOME`), custom `-c PATH` removes just the file.
- **config**: `--get|--set|--list` (positional `dfm config list` invalid). `--default` prints the default config TOML to stdout (`config_to_string`, byte-identical to what `init` writes; works before init, redirectable to restore defaults). `--set` array syntax for `force_encryption_for`: `add:<re>` (validated, non-empty), `rm:<elem>` (exact, removes ALL, error if none), `rmi:<idx>` (0-based, error if invalid); plain value on array / prefix on scalar → `InvalidInput`; **unknown param checked before syntax** ("not found"); `add:` repairs an absent/corrupted non-array value. Whole-table rewrite via `toml::to_string_pretty`.
- **status**: Phase 1 `state.syncs` → codes (checked against BOTH ignore files; source-ignored → `!!`, never `!?`); Phase 2 walk target for unmanaged/ignored; Phase 3 stale-pattern detection **full-tree only**. Codes: `--` ok, `MM` both, `M ` target, ` M` source, `NM` never-synced, `!?` unpulled, `??` unmanaged, `?L` unmanaged symlink, `LL` managed symlink, `!!` ignored, `!L` ignored symlink, `!P` stale pattern. Default view: git header (`git -C <source> status --porcelain -b`), dirs collapsed `dir/*`, paged only when output > terminal height **and** stdout is a terminal (`IsTerminal`). Path scoping: absolute or target-relative (or source → mapped back); scoped reports skip the stale block; `--short`/`--porcelain` uncolored/unpaged; filters `-a -c -m -U -M -p -e -i -l -u`. Filter flags combine **additively** (union; `--managed --unmanaged` shows both); `-e/--encrypted` overrides the others (keeps encrypted in every category, suppresses stale block, still respects `show_unpulled = unpulled || all` — pure `-e` keeps Unpulled hidden). `(encrypted)` marker right-aligned in default report only (same column as `(pattern)`; `dir/* (encrypted)` for wholly-encrypted folded dir, mixed dir folds without marker — members show under `-e`); `--short`/`--porcelain` never show it. Unpulled block excluded from the default report (only `--unpulled`/`--all`).

## Encryption (crypt.rs)
Self-contained **DFMENC** blob (`FORMAT_VERSION = 3`). Header: Argon2id `(m_cost KiB, t_cost, p_cost)`, 16B salt, 24B nonce, chunk_size u32, plaintext_len u64. Key: Argon2id (release 64MiB/t3/p4; debug 8MiB/t1/p1). Payload = chunked XChaCha20-Poly1305 records (ct ≤ 64 KiB + 16B tag); per-chunk nonce = base nonce with last 8B := 7B BE counter + final-flag byte; per-chunk AAD = header||idx||flag → reorder/dup/truncate/splice all fail auth. **Streaming: peak RAM O(chunk)**. Metadata: inner name, file mode, non-encrypted entry per enclosing dir (restores e.g. 0700 `.ssh` on pull); `decrypt` caps KDF params (m ≤ 16GiB, t ≤ 10, p ≤ 1024). Wrong password: first-chunk auth failure only (retried once after clearing cache); later failures = "corrupted". Write: `<dest>.part` + rename. `obtain_password`: shell command piped to `sh` **stdin** (not `-c`, invisible in `ps`) else masked rpassword prompt; cache = process-global `Mutex<Option<String>>`. All notices → stderr.

## Traversal (list_directory)
`WalkDir::filter_entry`; no link following. `TraversalFilter::KeepMatching` (pull: keep rel-path matches, skip dot files AND dot dirs) or `PruneIgnoredDirs` (add/forget/status/ignore: keep all files, prune fully-ignored dir subtrees via `R+"/x"` sentinel). Root always kept (a named ignored path is entered); pruned dirs recorded and rendered as one `!! dir/` (status). `NotFound` passes path through; directories skipped.

## Conventions
- **Task pattern**: analysis queues task enums; execution loop runs them; `continue` never cancels already-queued tasks.
- **State dispatch**: `add`/`pull`/`merge`/`diff --editable` → `with_state` (state written only on success); `forget` → `with_state_even_if_error`; `status`/`diff` reporting → read-only borrow.
- **`main_logic`** resolves state/config as `Option`: unresolvable paths warn + continue (purge/paths work with `$HOME` unset); mutating commands then error via `with_state`.
- **No shell** for tool commands (whitespace-split, direct spawn).
- **Unreadable objects** (`PermissionDenied`) are skip-with-warning, never a command failure — in `list_directory`, per-file analysis, and task loops (except `NotFound`, which passes roots through; other errors fail the command).
- **Root guard** (lib.rs, first in `main_logic`): hand-rolled externs `getuid`/`geteuid` via `#[link(name="c")] unsafe extern` (edition 2024, no new dep). Refuse iff `euid==0 && (ruid!=0 || SUDO_USER non-empty)` — genuine root allowed. Error `InvalidInput`, exit 1; `--help`/`--version` still work. Unit `test_refuse_root_access_matrix`; no shell test. Suite counts: 232 shell, 46 unit (37 lib + 9 status-collapse).
- Installed `/usr/bin/dfm` predates the root guard; test euid-0 with `unshare -r`, never sudo.
## Testing conventions (launcher.sh)
Every test: subshell `set -eEu -x`, fresh temp `$HOME`, sandbox HOME + all four XDG vars (`mkdir -p`), prefers debug binary, never reads stdin. Helpers: `dfm()`, `write <content> <path>`, `assert`/`assert_succ`/`assert_fail`, `run_fail` (captures combined output into `$FAIL_OUTPUT`), `assert_source`/`assert_no_source`, `assert_content_eq`, `add_file`, `assert_encrypted` (`$PASSWORD`), `uuid`.
**Grep rule**: positive → plain pipeline. Negative → **never** `! cmd | grep -qF` (POSIX `-e` skips `!`-inverted → false-pass); capture first, then grep only: `RES=$(...); assert_fail grep -qF "pat" <<<"$RES"`. Expected failures → `run_fail dfm ...` then `assert_succ grep -qF "msg" <<<"$FAIL_OUTPUT"`. Under `set -e`, rescue `$(… dfm …)` non-zero rc with `|| true`. Files starting with `-`/`+` need `grep -qF -- "-$VAR"`. Redirect stderr to a file to check it.

## Manual testing (without launcher.sh) — caveats
- **Sandbox everything**: fresh HOME + all four XDG dirs (`mkdir -p`); **debug build** `target/debug/dfm`. Never run dfm against the real `$HOME` (add/pull/forget act on whole trees). Don't install the built distributive.
- Set the toolchain PATH before building (see Build/test).
- `unshare -r` verifies the root guard (fake `SUDO_USER` refused; `DFM_ALLOW_ROOT=1` bypasses; genuine root runs). `sudo` runs the stale `/usr/bin/dfm`.
- `dfm config list` is invalid syntax (needs `--get/--set/--list`); missing-key `config get` warns, exit 0.
- Avoid interactive password prompts: clear stdin (`< /dev/null`).
- Paging (`print_paged`) only spawns `$PAGER` on a TTY stdout — piping is safe. `run_fail` env assignments must use `env K=V "$BIN"` form.
## Debug strategies (in order)
1. Run the failing test alone: `bash tests/launcher.sh test_x.sh` (full `-x` trace); read the failing assertion + lines above before touching code.
2. Trace OK but output wrong → add **one** `eprintln!` where the asserted value is computed, compare; read the function end-to-end to confirm the hypothesis.
| Symptom | Likely cause |
|---|---|
| `grep` 1 on `dfm status` | entry in a hidden category (`LL`/`--`/`!!`/`!L`) — try `--all`/`--short` |
| pointer-file `test -f` fails | `.symlink` postfix appended to the full filename |
| `assert_source` fails | dot-prefix/postfix/path-component mismatch in the computed source path |
| queued task still runs after `continue` | tasks already queued execute in the final task loop |
## Roadmap
`ROADMAP.md` is the current feature plan (all items through ambiguity-elimination, `RESOLVED`). Key decisions:
- `status --encrypted` (`-e`) overrides other filters; filters additive (no contradictory-flag error); `(encrypted)` marker human-only (right-aligned; `dir/* (encrypted)` when whole group).
- Auto-encrypt when any component (target-root down) has `mode & 0077 == 0`; unions with `force_encryption_for`; newly added only; symmetric on pull.
- `sync`: synced+modified only; BothModified = conflict (no `--force` → nothing modified, exit≠0; `--force` → skip conflicts, exit 0).
- `diff --all` (`-a`) default via config `diff_all_default`; template `diff_all_tool_command` default `diff -u --color=always {source} {target}` (reversed for SourceModified) executed via `sh -c`; BothModified diffed, never-synced silent; encrypted decrypted to scratch.

- `status <path>` one path, nothing to report → `<path> is up-to-date.`
- Documents: GPL-3.0-only in a separate LICENSE file; README states pure-local sync. **DONE**: README.md and context.txt trimmed to pre-agreed per-section line budgets (README 690 → 331; context 153 → 107).
