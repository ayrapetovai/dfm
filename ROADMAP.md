# Status subcommand
[-] Must give information in form of list, wehre are filenames next to statuses are listed. If the list is more than 20 elements the prompt for use must be used to pause the output of the list, a proceed only after user pressed "enter".
[-] Must show what source files are not pulled.
[-] Must show what target files are not managed and not ignored.
[-] Show managed files and synchronization status: target modified, source modified, both modified, none modifer; can pull without merge, can add without merge.
[-] Show ignored files and with what regular expressions they were filtered.
[-] Show regular expressions that do not filter any files.
